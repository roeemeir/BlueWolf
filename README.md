# זאב כחול

מאגר אחוד למערכת זאב כחול.

## מבנה המאגר

- `app/` — יישום Next/Vinext בעברית RTL ו־API לשמירת סביבת העבודה.
- `components/bluewolf/` — מסך חי, תחקור לאחור, מצב מפתחים ורכיבי ההמחשה.
- `db/` ו־`drizzle/` — סכמת D1, מיגרציה ויומן שינויי קונפיגורציה.
- `core/` — ליבת Python העצמאית, מפרט V1, בדיקות וסימולטור.
- `.github/workflows/ci.yml` — בדיקות אוטומטיות לליבה ולממשק בכל עדכון.

## מצב נוכחי · v0.3

האתר המקוון הוא סביבת מוצר אינטראקטיבית המבוססת על נתוני סימולציה דטרמיניסטיים
בטיק קשיח של 5 שניות. הוא כולל Material Liquid Glass ומצב כהה/בהיר, מפה חיה
עם אנימציית רכבים ואייקונים לפי סוג, SI בשלוש טבעות, SO במבנה ח׳ עם היפודרום
כפול במרכז, החלפת שרת אמיתית, בחירת תבנית חיה עם הטלה חזותית, גרף רב־קבוצתי,
התראות עשירות וציון מספרי לכל רכב.

מצב המפתחים כולל מחולל קונסטלציות SI/SO ללא כפילויות סימטריה, זרימת GT מלאה
מבחירת שרת וטווח עד אישור ותיוג, סינון בנק GT, Token ומיפוי Influx מפורט לכל
שדה, בנק נתיבים מסונן, שרתי מפות, תיאורי ספים ואייקוני רכב. תחקור לאחור מפיק
דוח PDF ממותג ובו פירוט מקטעים, ציוני קבוצה ורכב ו־root causes.

הפריסה הציבורית אינה יכולה להגיע לרשת InfluxDB סגורה ואינה מריצה את ליבת Python
בתוך ה־Worker. מסך המעבר ל־Influx מציג במפורש מצב ממתין כל עוד החיבור אינו
מוגדר. ליבת החישוב נשארת בתיקיית core כרכיב עצמאי כדי שאפשר לשדרג אותה בלי
להחליף את המעטפת ולחבר אותה בשירות Windows/OpenShift המבצעי.

## בדיקות

ליבה:

```bash
cd core
PYTHONPATH=src python -m unittest discover -s tests -v
```

ממשק:

```bash
npm ci
npm run db:generate
npm run lint
npm test
```

בדיקת טיפוסים:

```bash
npx tsc --noEmit
```

הפריסה המבצעית המתוכננת היא לשרת Windows ברשת סגורה ובהמשך ל־OpenShift. הפריסה
המקוונת הנוכחית נועדה להמחשה ולעבודה משותפת בלבד.
