# זאב כחול

מאגר אחוד למערכת זאב כחול.

## מבנה המאגר

- `app/` — יישום Next/Vinext בעברית RTL ו־API לשמירת סביבת העבודה.
- `components/bluewolf/` — מסך חי, תחקור לאחור, מצב מפתחים ורכיבי ההמחשה.
- `db/` ו־`drizzle/` — סכמת D1, מיגרציה ויומן שינויי קונפיגורציה.
- `core/` — ליבת Python העצמאית, מפרט V1, בדיקות וסימולטור.
- `.github/workflows/ci.yml` — בדיקות אוטומטיות לליבה ולממשק בכל עדכון.

## מצב נוכחי

האתר המקוון הוא סביבת מוצר אינטראקטיבית המבוססת על נתוני סימולציה. הוא כולל
Material Liquid Glass, מצב בהיר וכהה, מסך חי, תחקור, יצוא דוח, מחולל תבניות,
משקולות וספים, GT/Sweep, בנק נתיבים, מיפוי Influx, הגדרות ובדיקות מערכת. פעולות
קונפיגורציה נשמרות ב־D1 עם fallback מקומי בדפדפן.

הפריסה הציבורית עדיין אינה מתחברת לרשת InfluxDB סגורה ואינה מריצה את ליבת
Python בתוך ה־Worker. ליבת החישוב נשארת ב־`core/` כרכיב עצמאי כדי שאפשר יהיה
לשדרג אותה בלי להחליף את המעטפת, ולחבר אותה בשירות Windows/OpenShift המבצעי.

## בדיקות

ליבה:

```bash
cd core
PYTHONPATH=src python -m unittest discover -s tests -v
```

ממשק:

```bash
npm ci
npm run db:generate
npm run lint
npm test
```

בדיקת טיפוסים:

```bash
npx tsc --noEmit
```

הפריסה המבצעית המתוכננת היא לשרת Windows ברשת סגורה ובהמשך ל־OpenShift. הפריסה
המקוונת הנוכחית נועדה להמחשה ולעבודה משותפת בלבד.
