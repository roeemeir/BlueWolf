# זאב כחול

בסיס הייצור החדש של מערכת זאב כחול. המערכת מזהה נתיבים סגורים מתוך נתוני ניווט,
משייכת רכבים לקבוצות סנכרון ומחשבת ציוני נתיב וסנכרון ברמת הרכב וברמת הקבוצה.

## עקרונות

- הליבה האלגוריתמית היא חבילת Python עצמאית ואינה מכירה InfluxDB, SQLite, UI או PDF.
- אותו מנוע משמש לחי, לעיבוד היסטורי ולסימולטור.
- כל הזמנים נשמרים ב־UTC; אזור הזמן משפיע על התצוגה בלבד.
- כל הנתיבים מיוצגים כנתיב מחזורי גנרי; `SI` ו־`SO` הן אסטרטגיות סנכרון.
- השיוך לקבוצה מבוסס על גיאומטריה, מחזור וכיוון רלוונטי בלבד — לעולם לא על הציון.
- לכל רכב בקבוצה יש ציון סנכרון, נתיב וכולל; ציוני הקבוצה נגזרים מהם.

המפרט המקובע נמצא ב־[`docs/V1_SPEC_HE.md`](docs/V1_SPEC_HE.md).

## מצב המימוש

הגרסה הנוכחית היא אבן הדרך הראשונה:

1. חוזי נתונים יציבים.
2. קונפיגורציית ברירת המחדל שאושרה.
3. מנוע ציונים טהור ודטרמיניסטי.
4. גיאומטריית נתיב מחזורית ומנוע התאמת תבניות ללא תלות במזהי רכבים.
5. `CoreSession` מצבי עם checkpoint גרסאי.
6. Join זמני למטריקות Influx נפרדות, ללא `TTAG`.
7. סימולטור בסיסי ובדיקות שקילות Batch/Increment.

אב־הטיפוס `blue-wolf-offline-v0.6.0` נשמר כהפניה חזותית בלבד ואינו בסיס הליבה.

## בדיקה מקומית

אין צורך בתלויות חיצוניות כדי להריץ את בדיקות הבסיס:

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

הרצת הדגמה:

```bash
PYTHONPATH=src python scripts/run_core_demo.py
```

בדיקת־עצמי מסכמת לאבן הדרך הנוכחית:

```bash
PYTHONPATH=src python scripts/run_core_self_test.py
```
