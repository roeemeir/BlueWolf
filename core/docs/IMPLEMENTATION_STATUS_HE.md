# מצב מימוש

## התשובה הקצרה

האפיון של V1 מספיק כדי להתחיל ולבנות. אין כרגע שאלה מוצרית שחוסמת את המימוש.
החלטות שעוד ישתנו בעקבות נתוני אמת יישארו בקונפיגורציה ולא ייקבעו בקוד קשיח.

## אבן דרך 1 — הושלמה

- מפרט V1 מאוחד ומצומצם.
- חוזי קלט ופלט גרסאיים של הליבה.
- ייצוג גנרי לנתיב סגור ולמשפחות `SI` ו־`SO`.
- כל המשקולות והספים שאושרו.
- ציון סנכרון, נתיב וכולל לכל רכב.
- ציון קבוצה הנגזר מציוני הרכבים התקפים בלבד.
- מעטפת `CoreSession` זהה ל־Batch ול־Increment.
- checkpoint לוגי, נייד וגרסאי.
- סימולטור SI דטרמיניסטי בסיסי.
- Join זמני דטרמיניסטי למטריקות Influx נפרדות, ללא `TTAG`.
- גיאומטריית נתיב מחזורית משותפת: פאזה לפי אורך קשת, הטלה, משיק ועקמומיות יחסית.
- התאמת תבנית ללא תלות במזהה הרכב, כולל פאזה משותפת ויחסי SO הפוכים.
- בדיקות יחידה ובדיקת־עצמי מסכמת.

## אבני הדרך הבאות

1. זיהוי נתיב `SI` ו־`SO` מתוך ניווט, כולל ייצוג observed/effective וחסינות לבליטה.
2. קיבוץ, יציבות `group_id`, יצירת בנק תבניות והפקת יתר מדדי הסנכרון.
3. מנגנון אירועים, התראות, תיקון נתונים מאוחרים ושמירה מקומית.
4. מתאם InfluxDB 2 ומצב polling ער/רדום.
5. API ומסכי מפעיל/מפתח בעברית RTL.
6. תחקור, PDF, בנק נתיבים אינפורמטיבי וסימולטור מלא.
7. מתקין Windows וחבילת OpenShift.

כל אבן דרך תתווסף לאותו מאגר ותעבור בדיקות שקילות בין עיבוד חי, Batch ושחזור
מ־checkpoint. כך לא נבנה שלוש גרסאות שונות של האלגוריתם.
