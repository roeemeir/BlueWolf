# זאב כחול — מחזור חיים לבחירת תבנית SO

מסמך זה מקבע את התנהגות בחירת התבנית בהתאם ל־`V1_SPEC_HE.md`, ללא הוספת semantics חדשים.

## 1. מקור התבניות

- רק תבניות שאושרו על ידי מפתח ונמצאות ב־`SOTemplateBank` הן חוקיות.
- התבניות הרלוונטיות מסוננות לפי constellation של הקבוצה בלבד: שרשרת `RouteKind` + multiset של `vehicle_type` לכל Route Instance.
- `vehicle_id`, גאומטריה בפועל, group score ו־sync score אינם חלק ממפתח ה־constellation.

## 2. בחירה פעילה

לכל `(group_id, constellation)` קיימת לכל היותר בחירה ידנית אחת.

סדר הקדימויות:

1. בחירה ידנית שמורה עבור אותו `group_id` ואותה constellation, אם היא עדיין חוקית ורלוונטית.
2. תבנית developer-default עבור אותה constellation.
3. אם אין default — אין תבנית פעילה עד שהמפעיל בוחר אחת במפורש.

בחירה ידנית אינה עוברת אוטומטית ל־`group_id` אחר או ל־constellation אחרת.

## 3. שמירה וגרסאות

- בחירת מפעיל נשמרת מיידית.
- כאשר bank/version משתנה, הבחירה נשמרת רק אם `template_id` עדיין קיים ורלוונטי לאותה constellation; אחרת היא נפסלת במפורש.
- אירוע קיים שומר את גרסת התבנית שחלה עליו; event/version persistence שייך ל־Event Engine ולא למודול הבחירה עצמו.

## 4. המלצה על תבנית חלופית

המלצה היא שכבה נפרדת מבחירה פעילה:

- תבנית חלופית מוצעת רק אם היא טובה מן התבנית הפעילה ב־30 נקודות במשך 120 שניות רצופות של evidence תקף.
- הצעה פעילה נסגרת אם היתרון יורד מתחת ל־15 נקודות במשך 30 שניות רצופות.
- דחיית ההצעה מסתירה אותה עד סוף האירוע הנוכחי.
- המלצה לעולם אינה מחליפה תבנית אוטומטית; היא רק יוצרת `TEMPLATE_SUGGESTED`/מצב הצעה למעטפת.

## 5. גבולות אחריות

מודול הבחירה:

- אינו יוצר תבניות.
- אינו משנה group membership.
- אינו מחשב score בעצמו; הוא צורך תוצאות score/fit מבחוץ לצורך recommendation lifecycle בלבד.
- אינו תלוי ב־vehicle ID לצורך template semantics.
- אינו ממציא default כאשר מפתח לא הגדיר default.
