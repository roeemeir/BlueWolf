# הפעלה מקומית עם SQLite — ללא גרסאות בדיקה חלקיות

עודכן: 23/09/2026. המסמך מתאר הרכבת סביבת Offline, **לא אישור למסירת גרסה לבדיקת מערכת**. בהתאם לנספח `QA-E2E-20260923` במפרט Master המקורי ול[שער ה־E2E](../docs/E2E_QA_RELEASE_GATE_HE.md), אין למסור קישור לבדיקת המוצר לפני שה־Web, SQLite, Python Core התפעולי ו־InfluxDB2 מוזנים ומאומתים יחד, כולל אירועים, תחקור ו־PDF. אסור להחליף Core שאינו מחובר בשירות QA בלבד, דמו דפדפן או נתוני תבנית סטטיים ולהציג תוצאות כציונים מבצעיים.

## הרכבה מקומית

1. התקינו Node/Python מהגרסאות הנתמכות, תלויות מה־lockfile, ובנו `npm run build:offline`. הפעילו `node scripts/start-offline.mjs` עם `BLUEWOLF_STORAGE=sqlite` ו־`BLUEWOLF_SQLITE_PATH` המצביע למיקום קבוע וניתן לכתיבה. כל הדפדפנים באותה התקנה חולקים את סביבת `installation`.
2. הפעילו את שירות Python במצב operational באותו אתר ריצה והגדירו `BLUEWOLF_OPERATIONAL_CONFIG` לקובץ JSON מלא, שאינו קובץ example, עם שלושה שרתים, קבוצות SI/SO, בנק תבניות, מיפוי Influx ופרטי מסלולים מאושרים. הגדירו token דרך `BLUEWOLF_INFLUX_TOKEN` ללא שמירתו במפרט, בלוג או ב־SQLite. Web מתחבר דרך `BLUEWOLF_CORE_API_URL`; אם נדרש Bearer token, הגדירו אותו בשני הצדדים.
3. עבור מיפויי Influx שנשמרים ב־Workspace, חברו את `BLUEWOLF_WORKSPACE_DB` ב־Core למסד התקנת ה־Web, ואת `BLUEWOLF_OPERATIONAL_CONFIG` באותו מקום ש־Web משתמש בו לעדכון התצורה התפעולית. שינויים שבוצעו ב־Web דורשים אימות החלה בפועל ב־Core, ובמקום שעדיין נדרש restart — הפעלה מחודשת מבוקרת ואימות checksum/version.
4. בדקו `/readyz` במצב `operational`, `running=true`, לפחות שני טיקים וללא שגיאות שרת, ולא רק `/healthz`. בדקו נתונים שנצפו בפועל והתעדכנו בכל שלושת השרתים, הנתיב שה־Core זיהה, קבוצתיות/ציונים, מפות ונקודות ניווט. בדקו קריאה/כתיבה ב־SQLite, קונפליקטים, שחזור לאחר הפעלה מחדש, אירועים, החלת תבנית מתחילת אירוע, תחקור ו־PDF, סנכרון גרף/מפה והצגת נתונים חסרים ככאלה.
5. בצעו קבלת דפדפן ו־iPhone לאוסף הדרישות המעודכן: SI מציג הפרשים בין סמוכים ומפה קוהרנטית; SO מציג רכבים וכיוון על ההיפודרומים; רכבים תמיד גלויים, אין שכבות בסיס/קבוצות, גורמי סטייה בעברית, עקבות תחקור כ־scatter ומפות ביחס צירים שווה, בנק נתיבים עם גרירה ו־WKT במצב עריכה בלבד, הוספת נתיב לפי מרכז/רדיוס/אורך/כיוון, שרתים עצמאיים עם תרחישים משתנים ומסך הגדרות מותאם iPhone.

## מגבלות שאסור להסתיר

מפת הנדסה עובדת גם ללא אריחים, אך WMTS/WMS נצפים רק כששרת מפות מקומי/פנימי מספק אותם. בדיקות יחידה ל־Core, בדיקות SQLite נפרדות ו־HTTP 200 של Web אינן מחליפות בדיקת E2E משותפת. נתוני בדיקה סינתטיים מותרים רק כאשר הם מוזרמים למקור הנתונים ועוברים את **אותו** Core תפעולי, תוך סימון ״נתוני בדיקה״ ברור. אם Influx אינו מחובר, הארכיון חסר, Core אינו מייצר נתיב מזוהה או אין הוכחה להחלת תבנית — הסטטוס חסום ולא נוצר/נמסר URL בדיקות.

המסמך `deploy/README_HE.md` מפרט את מדדי המוכנות וה־workflow הפרטי. `BW-GOV-010` נשאר חסום עד סקירת קוד↔שני מסמכי המקור, ללא שינוי fingerprint לצורך CI בלבד. אין מיזוג ל־main או שחרור לייצור ללא אישור מפורש.
