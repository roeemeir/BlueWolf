# Blue Wolf — Current Official SRS

The official, mandatory product specification is the union of:

1. `docs/BLUE_WOLF_SRS.md` — authoritative baseline.
2. `docs/BLUE_WOLF_SRS_CHANGESET_2026-09-06.md` — normative amendment v1.1.

**Precedence rule:** the newest normative amendment wins only where it explicitly conflicts with an older requirement. All other baseline requirements remain mandatory.

Every release must be checked against both documents. No feature may be declared implemented merely because a UI mock or hardcoded value exists. Release evidence must distinguish executable implementation, external integration and demo-only behavior.
